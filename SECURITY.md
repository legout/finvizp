# Security policy

## Supported versions

`finvizp` has not released a stable version. Security fixes apply to the current
`main` branch until a release-support policy is published.

## Reporting a vulnerability

Please do not disclose vulnerabilities, credential exposure, entitlement bypass,
or unsafe request behavior in a public issue. Report them privately to
`volker.lorrmann@gmail.com` with enough detail to reproduce and assess the
problem.

Do not include live account credentials, cookies, proxy credentials, or personal
data. Redact sensitive values and use minimal synthetic evidence where possible.
