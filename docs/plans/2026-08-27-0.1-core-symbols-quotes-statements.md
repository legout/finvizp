# finvizp 0.1 Core, Symbols, Quotes, and Statements Implementation Plan

> **For Hermes:** Execute through the `finvizp` Kanban cards in dependency order. Each code card uses strict RED→GREEN TDD and same-card review.

**Goal:** Build the trustworthy reusable foundation and ship symbol discovery, complete quote bundles, and all six public statement forms.

**Architecture:** Contracts come first, followed by schema normalization and transport/cache as independent deep modules. Endpoint cards consume those interfaces. The integration card alone curates package exports, capability status, docs, and bounded live evidence.

**Tech Stack:** Python 3.11–3.14, `uv`, `fastreq[curl]`, lxml, PyArrow, pytest.

**Required interface:**

- `ResultStatus`: `COMPLETE`, `PARTIAL`, `EMPTY`.
- `AccessTier`: `PUBLIC`, `AUTHENTICATED`, `ELITE`, `UNKNOWN`.
- Frozen/slotted `ResultMetadata`, `FetchWarning`, `UnitError`, completeness counts, symbol-resolution records, and generic `FetchResult[T]`.
- `.data` is canonical; `.table`/`.artifact` validate the runtime kind and raise a typed data error on misuse.
- Public error hierarchy exactly distinguishes transport, rate limit, blocked, entitlement, not found, query, partial, batch, parse, and data failures.
- Strict partial exceptions carry an immutable partial result.
- Error/context formatting recursively redacts credentials, cookies, authorization values, proxy URLs, query secrets, and response bodies.
- `normalize_symbols()` trims/uppercases, maps reviewed dot/slash class notation to dashes, rejects unknown punctuation, deduplicates by canonical symbol, and preserves every requested position/spelling.
- `run_sync()` works outside an event loop and raises a clear `RuntimeError` inside one; it never starts a nested loop.

2. Implement only the enums and frozen records; rerun to GREEN.
3. Add `.table`/`.artifact` misuse and completeness-invariant tests; observe RED; implement minimal validation.
4. Add exception inheritance and partial-result tests; observe RED; implement the hierarchy.
5. Add secret-bearing nested-context tests and assert neither full values nor credential substrings appear; observe RED; implement generic safe context formatting.
6. Add symbol cases for `brk.b`, `BRK/B`, `BRK-B`, duplicates, blank input, order, and unknown punctuation; observe RED; implement normalization.
7. Add async-to-sync success and active-loop rejection tests; observe RED; implement `run_sync()`.
8. Run all five focused test files, then repository gates.

**Constraints:** No PyArrow construction, transport, endpoint URLs, cache, logging, or environment reads. Do not expose mutable dictionaries in frozen records; normalize to immutable mappings/tuples.
