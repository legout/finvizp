# finvizp 0.3 Groups, Maps, and Events Implementation Plan

> **For Hermes:** Execute after the 0.2 audit with strict TDD, isolated worktrees, same-card review, and merge-before-completion.

**Goal:** Add public groups, structured maps, global/publisher news, global/fund/manager insider feeds, and economic calendar/detail operations.

**Architecture:** Event families share source-near parsing and temporal normalization behavior through internal helpers, not a broad public base class. Groups use typed query registries. Maps return a compound structured bundle, never a renderer. Every enumerated-page operation remains caller-requested and bounded.

**Tech Stack:** Existing 0.1/0.2 foundation, lxml, first-party embedded JSON where contract-complete, PyArrow.
