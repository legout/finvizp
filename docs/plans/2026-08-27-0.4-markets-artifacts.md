# finvizp 0.4 Markets and Artifacts Implementation Plan

> **For Hermes:** Execute after the 0.3 audit with strict TDD, isolated worktrees, same-card review, and merge-before-completion.

**Goal:** Add explicit chart/spectrum artifacts plus structured forex, crypto, and current futures data.
