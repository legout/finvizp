# API operations

All networked operations accept an optional `FinvizClient`. Async functions
end in `_async`; sync twins use the same name without that suffix.

The generated reference is split by use case:

- [Core operations](api-core-operations.md): symbols, statements, quotes, and
  quote projections.
- [Analysis operations](api-analysis-operations.md): screeners, signals,
  earnings, groups, and maps.
- [Market operations](api-market-operations.md): news, insider feeds,
  calendar, forex, crypto, futures, artifacts, and capabilities.

For behavior and examples, start with the conceptual references:
[screener](screener.md), [groups/maps/events](groups-maps-events.md), and
[markets and artifacts](markets-and-artifacts.md).
